# Sistema de Blog por Consola

## Descripción

Programa desarrollado en Python que permite administrar publicaciones de un blog mediante un menú interactivo por consola.

## Funcionalidades

- Ver todos los posts.
- Buscar publicaciones por título.
- Filtrar publicaciones por etiqueta.
- Validar la estructura de los posts.
- Salir del programa.


## Requisitos

Tener Python instalado.

## Ejecución

Desde la carpeta raíz del proyecto, ejecutar: ```bash
python main.py
```
